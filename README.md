# Remix of Wedding Photo Site

💍 PROMPT PARA O LOVABLE — WEDDING PHOTOGRAPHER PORTFOLIO

Crie um website de portfólio para um(a) wedding photographer premium, com foco absoluto em storytelling emocional, narrativa visual e estética cinematográfica.
O site deve parecer um filme dividido em capítulos, não um portfólio tradicional.

🎯 POSICIONAMENTO

Fotógrafo(a) de casamento autoral

Trabalha com casamentos intimistas, destination weddings e histórias reais

Mais sobre emoção e memória do que poses perfeitas

Público-alvo: casais que valorizam experiência, estética e significado

🎨 IDENTIDADE VISUAL
Estilo

Cinematográfico

Orgânico

Humano

Ritmo lento, contemplativo

Cores

Fundo: creme, bege ou off-white quente

Texto: cinza escuro / carvão

Cor de acento: dourado suave ou rosé discreto

Evitar branco puro e preto absoluto

Tipografia

Headings: Cormorant, Libre Baskerville ou similar

Corpo: Lora, Merriweather ou serif elegante

Tipografia deve transmitir tempo, memória e intimidade

🧩 ELEMENTO VISUAL ÚNICO (OBRIGATÓRIO)

👉 Story Chapters

Cada projeto é dividido em capítulos narrativos:

Before

The Moment

Forever

Esses títulos devem aparecer como parte do layout, não só texto

🏠 HOME
Hero

Slideshow lento (fade suave, sem transições agressivas)

Imagens em tela cheia

Texto minimalista sobreposto

Exemplo de headline:
“I don’t photograph weddings. I tell love stories.”

Subheadline curta e emocional.

Ritmo

Scroll longo

Poucas seções

Muito respiro

Nada apressado
